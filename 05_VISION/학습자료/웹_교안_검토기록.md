## 외부 렌더러가 없을 때

MathJax/Mermaid 스크립트를 제거한 임시 사본 두 개를 로컬 HTTP로 열었습니다. 이는 스크립트 미지원 상황의 모의 검사이며 실제 방화벽 차단 실험은 아닙니다. DNN은 렌더된 수식 0개 상태에서 `.math` 원문 170개와 본문 설명이 남았습니다. Attention은 SVG 0개 상태에서 Mermaid 원문과 ‘도표 원문 보기’를 펼칠 수 있었고, 패치·Encoder 흐름을 풀이하는 인접 문장과 비교표를 직접 확인했습니다 (`fallback.png`). 실제 출력 파일에는 정상 렌더러 설정을 유지했습니다.

## 남은 범위와 변경 관리

- 학습자 실험과 본문 실습 코드 실행은 이번 통합 담당이 수행하지 않았습니다. 담당별 본문 검토 기록과 구분합니다.

- GitHub Pages 등 배포는 하지 않았습니다. 로컬 HTTP의 경로·탐색 검증을 실제 배포 확인으로 확대하지 않습니다.
- 모든 후속 본문 수정 완료 통지 후 최종 재생성·전체 링크/fragment·코드·JS·HTTP·반복 생성 검사를 다시 통과했습니다. 입문 5.5절 확률 보강, DNN 읽기 순서 및 다음 §4 참조, 추적 문제5와 분할 문제6·7의 확장 학습 표기를 실제 브라우저에서 확인했습니다. 근거 화면은 `intro-probability.png`, `dnn-followup.png`, `tracking-followup.png`, `segmentation-followup.png`입니다. 이전 대표 화면은 변경되지 않은 부분의 검증에 사용하며 모든 화면을 최종판에서 다시 캡처했다고 주장하지 않습니다. 최종 파일 해시는 `tmp/vision-restructure/final-manifest.json`에 남겼습니다.
