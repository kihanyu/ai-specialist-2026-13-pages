# Vision Applications: 검출·추적·분할 학습 안내

CNN과 Attention으로 얻은 특징을 실제 시각 과제의 출력으로 바꾸는 과정입니다. **검출은 종류와 박스, 추적은 시간에 걸친 ID, 분할은 픽셀 영역**을 예측합니다. 상세 본문은 아래 세 문서가 기준입니다.

| 중심 질문 | 읽을 문서 | 핵심 목표 |
| --- | --- | --- |
| 무엇이 어디에 있는가? | [객체 검출](04_02_객체_검출.md) | IoU·NMS·AP 계산, R-CNN 계열·CenterNet·DETR 설계 비교 |
| 이전 프레임의 누구와 같은가? | [객체 추적](04_03_객체_추적.md) | ID 연결과 검출 오류 구분, ByteTrack·TrackFormer 이해 |
| 정확히 어느 픽셀에 있는가? | [영상 분할](04_04_영상_분할.md) | Semantic·Instance·Panoptic 구분, FCN·Mask R-CNN·U-Net·SegFormer·SAM 이해 |

처음 학습한다면 [CNN](02_02_CNN_Note.md) → [Attention과 ViT](03_02_Attention과_ViT.md) → 검출 → 추적 → 분할 순서를 권합니다. 분할만 필요한 경우 검출의 IoU와 RPN·RoI 개념을 복습한 후 분할로 이동해도 됩니다. 각 문서 첫머리의 선수지식과 기본·심화 경로를 따라 읽고 마지막 질문을 풀어 보세요.

모델을 선택할 때는 원하는 출력과 실패 비용을 먼저 정합니다. 박스가 맞아도 ID가 바뀔 수 있고, ID를 유지해도 픽셀 경계는 틀릴 수 있습니다. AP, 추적 지표, 분할 지표는 각각 다른 실패를 측정하므로 숫자만 직접 비교하지 않습니다.

원문은 [04_00_Applications.pdf](../교안/04_00_Applications.pdf)입니다. 쪽수는 PDF 실제 순서이며 검출은 3–35쪽, 추적은 37–61쪽, 분할은 63–101쪽에 대응합니다. 표지와 각 장 구분은 본문 개념 설명에서 제외했습니다. 원문의 실험 수치는 해당 설정의 결과로 읽고, 보충·정정·작은 계산은 각 상세 문서의 표시와 근거를 확인하세요.

복습 질문: “한 프레임에서 사람을 둘 다 찾았지만 다음 프레임에서 ID가 뒤바뀌었다”면 어떤 문서로 돌아가야 할까요? **추적**입니다. 검출 정답 여부만으로 시간에 걸친 동일성을 보장하지 못하기 때문입니다.
