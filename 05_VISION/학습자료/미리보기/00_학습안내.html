Vision 자습 교재: 이미지에서 예측과 영역까지

이미지는 숫자 배열이지만, 우리가 얻고 싶은 답은 종류·위치·영역·시간에 따른 동일성입니다. 이 교재는 입력과 정답을 정의하고 → 특징을 학습하고 → 목적에 맞는 출력을 만들고 → 결과를 평가하는 과정을 설명합니다. 교안을 옆에 펼쳐 두지 않고 본문과 예제, 확인 문제를 따라 읽는 것을 기본 경로로 삼습니다. 원본 PDF는 출처와 그림의 상세를 확인할 때 사용하는 참고 자료입니다.

1. 준비할 지식과 읽는 방법

Python의 변수·함수·반복문과 배열의 기본 사용을 알고 있다고 가정합니다. 텐서는 숫자를 여러 축으로 배열한 것이며, shape는 각 축의 길이입니다. 예를 들어 이미지 한 장의 높이·너비·색 채널을 각각 32·32·3으로 두면 숫자 3,072개를 담습니다. 여러 장을 한꺼번에 처리하는 배치 축과 채널 축의 위치는 구현에 따라 달라지므로 각 예제의 표기를 먼저 확인합니다.

처음에는 아래 순서대로 읽고, 각 문서의 작은 계산을 직접 따라 하세요. 확인 문제는 해설을 보기 전에 풀고, 틀리면 해당 정의나 중간 계산으로 돌아갑니다. 논문별 변형과 구현 상세는 기본 원리를 설명할 수 있게 된 뒤 읽어도 됩니다. 도표나 수식 렌더러를 사용할 수 없을 때도 인접한 설명·표·계산 과정을 함께 읽습니다.

실습 코드는 실행 환경과 입력 크기를 확인한 후 실행합니다. 예제에 적힌 예상 결과와 실제로 검증한 결과는 구분하며, 실행 여부는 해당 본문 또는 검토 기록에서 확인합니다.

3. 앞에서 배운 것이 다음 장에 쓰이는 방식

DNN에서는 입력을 예측으로 바꾸고 손실을 줄이는 학습 구조를 배웁니다. CNN은 이 구조 안에서 이미지의 가까운 위치를 함께 처리하고 같은 필터를 여러 위치에서 사용하는 방법입니다. ResNet은 CNN을 깊게 쌓을 때 입력을 더해 전달하는 경로를 추가합니다.

Attention은 토큰 간 관계에 따라 정보를 모읍니다. ViT는 이미지를 작은 패치로 나누어 이 계산에 넣고, DeiT·Swin은 학습과 구조의 조건을 바꿉니다. CLIP·DINO에서는 어떤 학습 신호로 표현을 만들지에 주목합니다. 이 방법들은 모두 서로 배타적인 모델 분류가 아니므로 구조와 학습 목적을 구분해서 읽습니다.

응용에서는 학습한 특징을 이용하되 답의 형식이 달라집니다. 검출은 위치와 종류, 추적은 시간에 걸친 ID, 분할은 픽셀 단위의 결과를 요구합니다. 따라서 네트워크 이름보다 먼저 출력 형식과 정답, 평가 기준을 정해야 합니다.

5. 전체 흐름 확인 문제

  1. 공장 영상에서 불량품의 종류만 고르는 경우, 위치까지 표시하는 경우, 불량 영역의 면적을 구하는 경우에 필요한 출력은 어떻게 다른가?
  2. RGB 이미지의 높이와 너비를 각각 두 배로 늘리면 입력 숫자 개수는 몇 배가 되는가? 채널 수는 그대로라고 가정한다.
  3. 같은 프레임의 물체 위치를 잘 찾았지만 다음 프레임에서 ID가 뒤바뀌었다. 어떤 과업의 문제가 남았는가?
해설과 복습 위치
  1. 종류만 고르면 분류 결과, 위치까지 표시하면 클래스와 박스, 면적을 구하려면 픽셀 단위 영역이 필요합니다. 실제 면적 단위로 바꾸려면 카메라 보정이나 픽셀 크기 같은 추가 정보도 필요합니다. 입문과 응용 세 문서에서 입력·출력 계약을 복습하세요.
  2. 원래 개수는 높이 × 너비 × 3입니다. 변경 후에는 (2 × 높이) × (2 × 너비) × 3이므로 4배입니다. 이 결과만으로 모든 모델의 계산량도 정확히 4배라고 단정할 수는 없습니다. 모델별 토큰 수와 연산 구조를 따로 확인해야 합니다. CNN과 ViT의 차원 설명으로 돌아가세요.
  3. 위치 검출 외에 시간에 걸친 동일성 연결, 즉 추적 문제가 남았습니다. 추적 문서의 연관과 ID 설명으로 돌아가세요.
