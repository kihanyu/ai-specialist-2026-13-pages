Vision: 이미지에서 의미를 읽는 모델

이미지를 숫자로 표현하는 방법에서 시작해 DNN과 CNN, Attention과 Vision Transformer, 검출·추적·분할로 이어지는 웹 교안입니다. 기존 노트 5개를 읽기용 HTML로 제공합니다.

학습 목표

  • 이미지 입력과 신경망 출력, 학습 손실의 관계를 설명합니다.
  • 합성곱과 잔차 연결의 역할을 설명하고 ResNet의 구조를 따라갑니다.
  • 이미지 패치와 Attention의 계산을 연결합니다.
  • 검출·추적·분할의 출력과 평가 기준을 구분합니다.

어디서 시작할까요?

Python의 함수와 배열, 텐서의 차원 표기를 알고 있다고 가정합니다. 처음 읽는다면 DNN → CNN → ResNet 구현 → Attention → Applications 순서로 이동하세요. 복습할 때는 각 문서의 내부 목차에서 필요한 개념을 고릅니다. 확인 질문과 예제가 있는 곳에서는 설명을 덮고 계산이나 흐름을 직접 재구성해 보세요.
