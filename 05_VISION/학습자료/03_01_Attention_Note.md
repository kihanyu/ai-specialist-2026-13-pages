# Attention 학습 지도

이 단원은 **이미지 안의 정보를 어떻게 모으는가 → 제한된 자원으로 어떻게 학습하는가 → 정답 신호를 어디서 얻는가**를 따라갑니다. 기존 긴 노트의 상세 설명·그림·수식·실험 해석은 아래 세 본문으로 옮겼습니다. 이 파일은 시작점이며 상세 본문의 중복본이 아닙니다.

## 먼저 준비할 것

[DNN](02_01_DNN_Note.md)의 행렬 곱·Softmax·교차 엔트로피와 [CNN](02_02_CNN_Note.md)의 특징 맵·지역 수용 영역을 알고 시작하면 좋습니다. 잔차 연결이 낯설면 [ResNet](02_03_CNN_ResNet_18Layer.md)으로 돌아가세요.

## 개념을 한 지도에서 연결하기

`패치 → QKV 관계 계산 → 이미지 특징`은 ViT의 구조입니다. 이 특징을 정답 라벨로 학습할 수도 있고, DeiT처럼 교사의 예측을 추가할 수도 있습니다. Swin은 관계를 계산하는 공간 범위를 바꿉니다. CLIP은 문장과의 대응을, DINO는 다른 이미지 뷰의 Teacher 출력을 목표로 삼습니다. 따라서 ViT·Swin 같은 **구조**와 CLIP·DINO 같은 **학습 방식**을 항상 배타적인 모델 선택지로 생각하면 안 됩니다.
