이 자료의 질문

모델을 작게 만들면, 실제 기기에서도 빨라질까?

모델의 크기와 실행 속도는 서로 관련이 있지만 같은 뜻은 아니다. 이 자료에서는 무엇을 줄였는지, 어떤 비용이 남는지, 품질에 어떤 영향이 있는지를 구분해 배운다.

배경지식이 없다면 여기서 시작하기

기초 용어 쉬운 뜻 이 자료에서의 역할
AI 모델 입력을 받아 예측을 만드는 계산 규칙 줄이거나 실행 방법을 바꿀 대상
가중치·파라미터 학습으로 정한 숫자 가지치기에서 제거할 후보
층(layer) 모델 안에서 입력을 변환하는 계산 단계 단계마다 중요도와 비용이 다름
학습 데이터로 가중치를 조정하는 과정 제거 후 품질 회복, 학생 모델 훈련
추론 학습한 모델로 새 입력의 결과를 계산하는 과정 장치에서 빠르게 수행할 작업
손실(loss) 예측이 목표와 얼마나 다른지 나타내는 값 학습 중 줄이려는 기준
활성값(activation) 입력이 층을 통과하며 만들어진 중간값 입력마다 달라지고 메모리를 사용함
토큰(token) 언어모델이 처리하는 글 조각 단어 전체 또는 단어의 일부일 수 있음
메모리 숫자·중간 결과를 보관하는 공간 모델이 작아도 실행 중 부족할 수 있음
지연시간 요청한 결과가 나올 때까지 걸리는 시간 실제 사용자가 기다리는 시간

가장 작은 모델 예제

입력 두 개를 y = 2 × x₁ + 3 × x₂로 계산한다고 하자.

  • 입력: x₁=1, x₂=2
  • 가중치: 2, 3
  • 출력: y=2×1+3×2=8
  • 가지치기 예: 두 번째 가중치를 0으로 만들면 출력은 2

가중치를 없애면 계산을 줄일 기회가 생긴다. 동시에 답도 달라질 수 있으므로 품질 확인이 필요하다.

읽는 순서

  1. 각 장의 시작 전 준비와 기본 개념을 읽는다.
  2. 그림에서 무엇을 봐야 하는지 확인한다.
  3. 작은 예제를 직접 계산한다.
  4. 확인 질문에 자신의 말로 답한다.
  5. 미분·행렬 수식이 필요한 심화 설명으로 돌아온다.

먼저 잡을 전체 관계

질문 주요 수단 줄이는 대상 먼저 확인할 위험
불필요한 연결을 없앨 수 있는가? 가지치기(pruning) 가중치·채널·연산 품질 손실, 희소 커널 미지원
더 작은 모델을 잘 학습할 수 있는가? 지식 증류(KD) 배포할 학생 모델의 크기 교사의 오류, 데이터·학습 비용
모든 과거 토큰을 읽어야 하는가? 희소 attention, KV 선택·양자화 attention 계산·KV 읽기와 저장 중요한 문맥 손실, 복원 비용
큰 모델을 매 토큰 호출해야 하는가? 투기적 디코딩 확정 토큰당 큰 모델 호출 초안·검증 비용, 낮은 수용률
같은 계산을 덜 이동하며 수행할 수 있는가? fusion, FlashAttention, patch 메모리 왕복·중간값·실행 overhead 장치·커널 제약, 중복 계산

방법을 조합하는 예

작은 학생 모델을 만든 뒤 증류로 학습하고, 양자화를 적용한 다음 최적화된 커널로 실행할 수 있다.

  • 모델 구조: 얼마나 작게 만들 것인가?
  • 학습 신호: 작은 모델의 품질을 어떻게 높일 것인가?
  • 실행 방법: 장치에서 어떤 비용을 줄일 것인가?
flowchart TD
    A[같은 입력·품질 조건으로 기준 측정] --> B{주요 병목은?}
    B -->|모델 크기·계산| C[가지치기 또는 작은 학생 + 증류]
    B -->|긴 문맥의 KV| D[선택·퇴거 또는 양자화]
    B -->|토큰별 순차 호출| E[초안 작성 + 큰 모델 검증]
    B -->|메모리 왕복·중간값| F[Fusion·FlashAttention·Patch]
    C --> G[목표 장치에서 품질·지연·최대 메모리 재측정]
    D --> G
    E --> G
    F --> G

그림은 병목에서 후보를 고르는 순서를 나타낸다. 실제 모델은 병목이 여러 개일 수 있고, 한 방법을 적용한 뒤 다른 병목이 드러날 수 있다. Mermaid 미지원 뷰어에서는 위 표를 같은 관계의 텍스트 대안으로 읽으면 된다.

자료를 읽는 방법

본문과 그림의 역할

  • 본문: 정의, 원리, 작은 계산, 오해하기 쉬운 점
  • 원문 그림: 구조, 연결, 축과 범례를 직접 확인하는 자료
  • 심화 수식: 기본 원리를 이해한 뒤 계산 근거를 확인하는 자료

그림의 영어 용어는 주변 해설에서 풀어 설명한다. 그림을 확대하기 어려워도 핵심은 본문과 표로 확인할 수 있다.

원문의 내용은 페이지를 표시하고, 새로 만든 작은 계산은 교육용 예제, 오기나 해석 주의는 정정·주의로 구별한다. 원문의 모델·제품·성능 수치는 당시 사례이며 현재 지원이나 보편적인 보장으로 읽지 않는다. 추가 대조에 사용한 논문·공식 문서는 해당 절에 링크했다.

각 장의 확인 질문은 먼저 해설을 접고 답한다. 틀렸다면 해설에 적힌 절로 돌아간다. 시험 출제 여부나 중요도는 원문에 없는 판단을 추가하지 않았다.
