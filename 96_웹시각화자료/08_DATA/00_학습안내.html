DATA 자습서: 시계열 예측과 추천시스템

이 폴더만으로 읽고 복습할 수 있다. 원본 PDF와 노트북에서 그림이나 코드를 찾아볼 필요가 없다. 도표와 발췌 이미지는 함께 들어 있고, 숫자 예는 모두 해당 장에서 제공한다. 실행 환경 없이도 설명·계산·비교 문제를 풀 수 있다.

시계열은 과거로부터 미래 값을, 추천은 상호작용 기록으로부터 항목 선호와 순위를 예측한다. 두 분야를 관통하는 질문은 “예측 순간에 무엇을 알고 있었는가?”다.

먼저 읽는 순서

장 중심 질문 읽고 나서 할 수 있는 일
1. 시계열 예측 기초 과거 어디까지 입력으로 쓰는가? 윈도우·기준 예측·오차를 계산한다.
2. 시계열 예측 심화 각 레이어는 어느 날짜를 읽고 무엇을 예측하는가? 시간축에서 지수평활, 순환 상태, 합성곱, 어텐션, 출력층의 역할을 구분한다.
3·4. 시계열 데이터 구성과 예측 평가 미래 정보를 섞지 않고 어떻게 비교하는가? 시간 경계와 스케일을 정하고 한 단계·다단계 평가를 구분한다.
5. 개인화 추천 시스템 같은 영화도 사용자마다 추천 순서가 왜 달라지는가? 취향과 기록으로 사용자별 점수를 만들고 후보 순서에 반영한다.
6. 그래프 기반 추천 이웃이 임베딩을 어떻게 바꾸는가? 방향·이분 구조를 구분하고, 메시지·집계·자기 연결에서 NGCF의 추천 점수까지 설명한다.
7·8. 추천 점수와 순위 평가 평점 오차와 추천 순위는 어떻게 다른가? 평점을 맞히는 모델과 순위를 매기는 모델을 비교하고 추천 결과를 평가한다.

시계열: 시간순 관측 → 과거 입력과 미래 라벨 → 예측 → 같은 시점끼리 비교.

추천: 상호작용 기록 → 후보 점수 → 정렬 → 숨겨 둔 정답과 비교.

읽기 전에 알면 좋은 용어

용어 이 자료에서의 뜻
특성 / 라벨 모델이 받는 값 / 나중에 정답으로 비교할 값
모양(shape) / 축 데이터 묶음의 각 방향 길이 / 각각 예·시간·특성처럼 의미가 붙은 방향
벡터 / 내적 숫자 묶음 / 같은 위치끼리 곱해 모두 더하는 계산
임베딩 사용자나 항목 같은 대상을 비교하고 계산하기 위해 나타낸 숫자 벡터
손실 / 지표 학습 시 줄이거나 최적화할 양 / 모델을 검증·보고할 때 쓰는 수치
누수 평가 때만 알 수 있는 정답이나 통계가 훈련·예측에 들어간 상태

장 안에서 본문 → 그림 → 숫자 예 → 확인 질문 순으로 읽는다. 계산 과정은 그림에서 단계별로 확인하고, 작은 화면에서는 그림을 눌러 크게 볼 수 있다. 약어는 각 장에서 처음 나올 때 전체 이름 뒤 괄호에 적었다.

그림과 본문에서 쓰는 약어

분야 전체 이름과 약어
예측 오차 평균 절대 오차(MAE), 평균 제곱 오차(MSE), 제곱근 평균 제곱 오차(RMSE), 평균 절대 백분율 오차(MAPE)
시계열 모델 자기회귀(AR), 단순 지수평활(SES), 오차·추세·계절 모형(ETS), 상태공간 모델(SSM)
신경망 다층 퍼셉트론(MLP), 순환 신경망(RNN), 장단기 기억 신경망(LSTM), 합성곱 신경망(CNN)
추천 모델과 학습 협업 필터링(CF), 신경망 협업 필터링(NCF), 베이지안 개인화 순위(BPR)
그래프 모델 그래프 신경망(GNN), 그래프 합성곱 신경망(GCN), 신경 그래프 협업 필터링(NGCF)
순위 지표 할인 누적 이득(DCG), 이상적 할인 누적 이득(IDCG), 정규화 할인 누적 이득(NDCG)
데이터 표현 식별자(ID), 단어 빈도·역문서 빈도(TF-IDF)

순위 지표의 @3은 상위 3개만 본다는 뜻이다. 예를 들어 정밀도(Precision@3)는 추천한 3개 중 몇 개가 맞았는지, 재현율(Recall@3)은 전체 정답 중 몇 개를 상위 3개에서 찾았는지 본다.

복습과 자가 점검에서 각 장의 원리를 섞어 설명해 보자. 그림의 출처와 검토 내용이 필요할 때는 제작 기록을 참고한다. 확인 질문은 자습용이며 시험 출제를 예고하는 자료가 아니다.
