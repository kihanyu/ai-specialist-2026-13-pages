시각화로 공부할 주제와 그림 읽는 법

RAG에서는 문서·벡터·확률·검색 상태가 서로 다른 형태로 변합니다. 글과 수식만 읽으면 어느 축을 계산하는지, 무엇이 저장되고 다시 사용되는지, 어떤 후보를 버렸는지를 놓치기 쉽습니다. 이 안내는 특히 그림이 도움이 되는 분야와 본문에 포함한 이미지를 연결합니다. 모든 그림은 이 폴더 안에 있으며 교안이나 HTML 파일을 열 필요가 없습니다.

어떤 분야에 그림이 중요한가

가장 우선해서 그림으로 볼 주제는 신경 검색 구조·벡터 탐색·청킹·확률 혼합·도구 사용·평가 분모입니다. 내부 상태와 여러 경로가 동시에 존재하기 때문입니다. 역색인·점수·순위 지표·RAG 전체 흐름·검색 고도화·근거 관리도 작은 예제의 대상을 그림으로 고정해 읽으면 계산과 설명이 연결됩니다.

분야 글만 읽을 때 놓치기 쉬운 점 포함한 시각화와 확인할 것
01 검색·역색인 같은 문서를 행렬의 열로 볼 때와 term별 목록으로 볼 때의 방향 차이 문서→행렬→posting, AND 커서 이동: term 횟수와 등장 문서 수, 후보와 관련성 순위를 구분
02 TF-IDF·BM25 희귀도·길이·횟수가 다른 위치에서 점수에 기여함 TF-IDF heatmap, BM25 곡선, 화면 발췌: 같은 문서·term을 세로로 추적하고 곡선의 포화와 길이 보정을 읽기
03 검색 평가 첫 관련 문서와 전체 관련 문서, 집합과 순서의 차이 순위와 지표, AP 순서 비교: 같은 Top-5 집합도 AP가 달라지는 이유
04 신경 검색 학습 Cross·Bi-Encoder의 만나는 위치와 연산 재사용, 점수 행렬의 두 축 인코더 비교, 점수→softmax→gradient: 사전 계산 가능 여부와 대각선 positive의 갱신 방향
05 벡터 인덱스 영역 하한·해시 경계·탐색 경로와 정답 후보가 다름 kd-tree·LSH, 그래프·HNSW: 가까운 점을 놓치는 조건, 후보 폭과 계층의 역할
06 RAG 구조 문서 변경 때 할 일과 질문마다 할 일을 섞기 쉬움 인덱싱·질의, 실패 위치: 근거가 어느 단계에서 빠졌는지 추적
07 청킹·컨텍스트 겹치는 구간과 중복 비용, 검색 단위와 읽는 범위의 차이 overlap 띠, parent·문맥 보강: 1,000토큰이 1,200토큰 저장량이 되는 이유와 parent 중복 제거
08 확률·디코딩 문서별 곱과 문서 간 합, 사전확률과 정답 기여도, 후보와 문서의 두 축 확률 경로, 기여도·gradient, 재평가 행렬: 0.32를 만든 항과 beam에 없던 항을 구분
09 검색 고도화 질의 변환·순위 융합·재정렬을 같은 단계로 보기 쉬움 Hybrid·RRF, 질문 변환·순차 hop: 후보를 새로 찾는 단계와 기존 후보 순서를 바꾸는 단계
10 답변·근거 인용 ID 존재와 실제 주장 지지를 혼동하기 쉬움 주장-근거 매트릭스, 답변 상태: 지지되지 않는 주장, 부분 답변·충돌·거절의 차이
11 도구·Agentic 학습 데이터 제작과 추론 실행, 프로토콜과 판단 알고리즘을 혼동하기 쉬움 Toolformer 학습·추론, Agent·MCP 역할: 누가 호출을 생성하고 누가 실제 실행하며 언제 멈추는지
12 평가·운영 지표마다 다른 분모, 평가 축의 차이, 캐시가 줄이지 못하는 비용 P와 CP, 검색·생성 진단, 캐시 비용 분해: 순서 가중과 단순 비율, 남는 비용을 구분

그림을 읽는 공통 순서

  1. 대상: 같은 질문·문서·배치·후보 집합을 비교하는지 확인합니다. 그림 사이에서 문서 A와 다른 장의 문서 A가 같은 자료라고 가정하지 않습니다.
  2. 축과 단위: 행과 열, 원시 횟수·토큰·거리·확률·비용 중 무엇인지 확인합니다. 화살표가 데이터 이동인지 학습 갱신인지도 구분합니다.
  3. 계산: 색이 진한 이유, 남아 있는 후보, 합산하는 항을 식과 연결합니다. 숫자가 함께 표시되어 있으므로 색만으로 판단하지 않아도 됩니다.
  4. 조건 변화: 하나의 근거가 빠지면, K나 후보 폭을 줄이면, 길이를 늘리면 결과가 어떻게 바뀔지 예상합니다.
  5. 한계: schematic 화살표는 실제 공간의 거리를 뜻하지 않을 수 있습니다. 가상 2차원 벡터는 실제 임베딩의 좌표마다 사람이 정한 의미가 있다는 주장이 아닙니다.

BM25 화면 발췌를 읽을 때

화면 발췌의 TF는 문서 내 원시 등장 횟수 f이며, TF-IDF 예제의 횟수/문서 길이와 다릅니다. 화면의 k는 본문의 포화 계수 k₁입니다. 표시 조건은 k₁=1.2, b=0.75이고 정지된 슬라이더는 이 조건을 보여 줍니다.

왼쪽은 평균 길이 조건에서 f를 늘릴 때의 빈도 항입니다. IDF를 곱하기 전이므로 전체 BM25 점수로 읽지 않습니다. 오른쪽은 f를 고정하고 상대 문서 길이를 바꿉니다. b=0이면 길이 영향이 없고, 길이 비율이 1일 때 여러 b 곡선이 만납니다. 화면의 작은 축·범례는 02장의 큰 SVG 그래프와 계산표로 함께 확인할 수 있습니다.

이미지와 본문을 함께 쓰기

이미지는 설명을 대신하는 장식이 아니라 검산할 대상과 과정을 고정하는 도구입니다. 각 이미지 다음의 ‘그림 읽기’에서 먼저 따라갈 경로와 주의할 오해를 읽고, 해당 절의 표·수식·확인 질문으로 돌아가세요. SVG는 개별 파일을 확대해 볼 수 있고, PNG는 촬영 시점의 고정 화면입니다. 이미지가 표시되지 않는 뷰어에서도 대체 텍스트·표·본문으로 같은 계산을 따라갈 수 있습니다.
