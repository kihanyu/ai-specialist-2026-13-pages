문서와 검색의 기본

용어 의미와 구별할 점 본문
Corpus 검색 대상으로 삼는 문서 집합. 평가에서 전체 관련 문서를 정의하는 범위도 이 집합과 연결됩니다. 01
Query 검색 요청. 사용자 질문 원문, 재작성된 검색어, 임베딩된 질의 벡터는 서로 다른 형태입니다. 01
Document / Chunk 원본 문서와 검색 단위인 조각. 한 문서에서 여러 청크가 나올 수 있습니다. 문서 단위·청크 단위 평가를 섞지 않습니다. 07
Term / Token 검색 전처리로 얻는 단어 단위와 모델 토크나이저 단위. 항상 같지 않으며, 글자 수와 토큰 수도 다릅니다. 02, 07
Term-document matrix 행·열을 단어와 문서에 대응시키고 빈도나 가중치를 저장한 행렬. 어느 축이 무엇인지 먼저 정합니다. 01
Inverted index / Posting list 단어에서 그 단어가 나온 문서 목록으로 가는 자료구조와 그 목록. 문서 ID·빈도·위치 등 저장 항목은 구현에 따라 다릅니다. 01
Boolean retrieval AND·OR·NOT 같은 조건으로 만족 문서를 찾는 방법. 관련성 순위 계산과는 별도입니다. 01
Sparse representation 좌표 대부분이 0인 표현. 고전적인 단어 가중치뿐 아니라 학습으로 만든 희소 표현도 있습니다. 02, 04
TF / DF / IDF 문서 내 단어 빈도 / 단어가 나온 문서 수 / 문서 집합 내 희귀도 가중치. TF와 IDF의 구체 공식은 변형이 있습니다. 02
BM25 IDF, 단어 빈도의 포화, 문서 길이 보정을 결합한 검색 점수. 점수 자체는 관련성 확률이 아닙니다. 02

신경 검색과 학습

용어 의미와 구별할 점 본문
Embedding 입력을 벡터로 나타낸 표현. 유사도는 학습 목적·정규화·도메인에 영향을 받습니다. 04
Dense retrieval 보통 학습된 밀집 벡터의 유사도로 문서 후보를 찾는 방식. 문서별 좌표에 단어 이름이 직접 붙는 것은 아닙니다. 04
Bi-Encoder / Dual Encoder 질문과 문서를 독립적으로 인코딩하는 구조. 두 인코더가 가중치를 공유하는지는 별도 설계입니다. 문서 벡터를 사전에 계산할 수 있습니다. 04
DPR Dense Passage Retrieval. 두 인코더 기반 검색의 대표적인 구체 방법이며, 모든 밀집 검색의 동의어는 아닙니다. 04
Cross-Encoder 질문·문서를 함께 입력해 상호작용을 계산하고 점수를 내는 구조. 전체 문서에 모두 적용하기보다 후보 재정렬에 자주 사용합니다. 04
ColBERT / Late interaction 질문·문서의 토큰 표현을 독립적으로 만든 뒤 토큰 수준에서 비교하는 방식. 단일 벡터 내적과 Cross-Encoder의 전체 상호작용 사이의 설계입니다. 04
Positive / Negative 특정 질문에 관련 있다고 학습하는 문서와 대비시키는 문서. 다른 질문의 positive가 현재 질문에도 관련될 수 있습니다. 04
In-batch negative 같은 배치의 다른 문서를 negative 후보로 재사용하는 방법. false negative 가능성을 관리해야 합니다. 04
Hard negative / False negative 모델이 헷갈리는 비관련 문서 / 실제로는 관련 있지만 negative로 붙인 문서. 둘은 같은 말이 아닙니다. 04
Softmax 여러 점수를 정규화된 분포로 바꾸는 연산. 분모에 어떤 후보를 포함했는지 확인합니다. 04, 08
Contrastive loss / InfoNCE 정해진 후보 집합에서 positive에 높은 상대 점수를 주도록 하는 손실. loss 식뿐 아니라 점수 생성 구조와 라벨이 중요합니다. 04

인덱스와 근사 검색

용어 의미와 구별할 점 본문
Inner product / Cosine 내적 / 벡터 길이로 정규화한 방향 유사도. 벡터를 단위 정규화한 경우 두 점수가 일치합니다. 05
k-NN / ANN 정한 거리·점수 기준의 최근접 이웃 검색 / 정확성을 일부 양보해 탐색 비용을 줄이는 근사 검색. 05
kd-tree 공간을 축에 따라 분할하는 트리. 영역의 최소 가능 거리로 가지를 잘라야 정확 검색 조건을 지킬 수 있습니다. 05
LSH 유사한 벡터가 같은 버킷에 들어갈 가능성이 높도록 설계한 해싱. 충돌은 이웃 후보를 모으는 기능입니다. 05
IVF 벡터를 군집 등에 배치하고 일부 목록을 탐색하는 인덱스 계열. 키워드의 inverted index와 인덱싱 기준이 다릅니다. 05
Graph ANN / HNSW 벡터를 노드로 연결하고 가까운 방향으로 이동하는 근사 검색 / 여러 계층을 이용하는 대표 구조. 05
Vector index / Vector DB 벡터 검색 자료구조 / 저장·갱신·필터·접근 제어 등까지 제공하는 시스템. 인덱스 알고리즘과 제품을 구분합니다. 05

RAG 파이프라인과 고도화

용어 의미와 구별할 점 본문
Retriever / Reader / Generator 후보를 찾는 구성요소 / 근거를 읽어 답을 만드는 역할 / 텍스트를 생성하는 모델. reader가 추출형인지 생성형인지 구체화합니다. 06
Indexing / Query time 문서를 검색 가능하게 준비하는 단계 / 질문이 들어와 결과를 만드는 단계. 비용·갱신 빈도가 다릅니다. 06
Chunk size / Overlap 조각의 크기 / 이웃 조각과 겹치는 범위. 단위, 중복 저장량, 경계에서 빠지는 정보를 함께 봅니다. 07
Parent-child retrieval 작은 조각으로 찾고 그 조각의 상위 문맥을 가져오는 방식. 검색 단위와 생성에 제공하는 단위가 다릅니다. 07
Contextual retrieval 조각의 원문 문맥을 설명하는 정보를 붙여 검색 표현 등을 보강하는 방법. 문서를 자르는 경계 결정과는 구별합니다. 07
Metadata filtering 문서의 날짜·권한·출처 등 속성으로 후보를 제한하는 것. 검색 전후 적용에 따라 누락과 비용이 달라집니다. 07
RAG-Sequence / Marginalization 출력 시퀀스에 대해 잠재 문서를 두는 RAG 모델 / 문서별 조건부 생성 확률을 문서 확률로 가중해 합하는 계산. 08
Top-k approximation / Beam search 문서 합산 범위를 제한하는 근사 / 생성 시퀀스 후보를 제한적으로 확장하는 탐색. 두 개의 후보 축을 구분합니다. 08
Thorough decoding 문서별 생성 후보를 모은 뒤 각 후보를 모든 검색 문서 조건에서 재평가하는 방식. 후보를 처음 만든 문서만 합하는 방식과 다릅니다. 08
Query rewriting / Decomposition 검색하기 좋은 표현으로 재작성 / 복합 질문을 하위 질문으로 분해. 재작성으로 원래 제약을 잃지 않아야 합니다. 09
HyDE / Step-back 가상 문서를 생성해 검색 표현으로 사용 / 질문을 상위 원리 수준으로 추상화. 가상 문서는 사실 근거가 아닙니다. 09
Hybrid retrieval / RRF 서로 다른 검색 방식을 결합 / 점수 대신 각 검색기의 순위를 이용해 융합. RRF 상수와 반환 문서 수를 구분합니다. 09
Reranking 1차 후보의 관련성을 다시 평가해 순위를 조정하는 단계. 후보 집합에서 빠진 근거를 새로 찾아주지는 않습니다. 09
Multi-hop 여러 근거를 연결해야 답할 수 있는 문제. 앞 단계 결과로 다음 검색어를 만들어야 할 수도 있습니다. 09, 11
Citation / Grounding / Abstention 출처 표시 / 주장에 근거 연결 / 충분한 근거가 없을 때 답을 보류·거절. 출처 표시만으로 주장 검증이 끝나지 않습니다. 10

도구 사용과 평가·운영

용어 의미와 구별할 점 본문
ToolFormer 호출 후보를 만들고 실행한 뒤 후속 토큰 예측에 도움이 되는 예를 골라 도구 사용을 학습하는 접근. 프롬프트만으로 도구를 연결하는 것과 구별합니다. 11
Agentic RAG 상태·도구 결과에 따라 검색과 판단을 반복하는 구조. 반복 상한·실패 처리·거절 조건이 필요합니다. 11
MCP 도구·자원 등에 연결하는 프로토콜. 검색 알고리즘이나 정답 보장 장치가 아닙니다. 11
Precision@K / Recall@K 상위 K개 중 관련 문서 비율 / 전체 관련 문서 중 찾은 비율. 분모가 다릅니다. 03
RR / MRR / AP / MAP 첫 관련 결과의 역순위 / 그 평균 / 관련 결과 위치의 정밀도를 모은 값 / 그 평균. AP에서 전체 관련 문서 수와 K의 관계를 정의해야 합니다. 03
ANN Recall@K 근사 검색 결과가 정확한 벡터 Top-K를 얼마나 재현하는지. 사람이 판정한 관련 문서 Recall과 다릅니다. 05
Context Precision / Context Recall 컨텍스트의 유용성·순서와 필요한 근거의 회수 정도. 선택한 지표 변형에 따라 reference·라벨 요구가 다릅니다. 12
Faithfulness / Answer Relevancy 답변 주장이 컨텍스트로 뒷받침되는 정도 / 답변이 질문에 맞는 정도. 실제 사실 정답성과 자동으로 같아지지 않습니다. 12
Golden set / LLM-as-Judge 대표 질문과 필요한 평가 정보를 관리하는 세트 / 모델이 기준에 따라 결과를 판정하는 방식. Judge도 편향·오판을 검증해야 합니다. 12
Regression evaluation 검색기·프롬프트·모델 변경 전후를 같은 평가 조건으로 비교하는 것. 정확도와 함께 거절·비용·지연도 추적합니다. 12
Prompt caching 반복되는 입력 접두부 등의 계산을 재사용하는 기능. 검색 결과 캐시·정답 캐시와 다르며 가격·유효기간·적용 조건은 제품마다 다릅니다. 12
