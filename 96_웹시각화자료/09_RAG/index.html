  2. 01. 검색의 기본과 역색인

    공통 어휘 축의 term-document matrix를 posting list로 바꾸고 TF와 DF를 구분한다. · 정렬된 두 posting list의 AND 커서 이동과 종료 불변식을 설명하고 빈 교집합을 처리한다. · Boolean 후보와 관련성 Top-K를 구분하고 조기 종료에 필요한 공통 정렬·동점 규칙·상한을 설명한다.

  3. 02. TF-IDF와 BM25

    원문 네 문서에서 길이·DF·avgdl을 구하고 이진 질의와 길이 정규화 TF-IDF 점수를 계산한다. · BM25의 원시 빈도·양수 IDF 변형·k₁·b·고유 질의 term 규약을 적용해 문서별 기여와 순위를 계산한다. · 포화와 길이 보정의 역할을 구분하고 f=0·k₁=0·어휘 밖 term·동점 조건을 설명한다.

    12개 절 · 계산 실습 1개

  4. 03. 검색 평가지표

    같은 순위 목록에서 Success·P·R·RR·AP·nDCG를 cutoff와 명시된 분모로 계산한다. · 전체 관련 수 r를 쓰는 AP@K와 다른 분모 변형, 질의별 MRR·MAP 평균을 구분한다. · 반환 부족·관련 문서 0개·미판정·중복·동점·평가 누출과 벤치마크 조건을 해석한다.

    16개 절 · 계산 실습 1개
