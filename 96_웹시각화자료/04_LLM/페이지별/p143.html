범위: 원문 PDF 파일 순서 143쪽. 슬라이드에 적힌 내용과 실제 그림을 기준으로 정리했다. 작은 활동은 교재의 교육용 보충이다.

핵심 내용과 용어

원문은 연속 실수를 유한 개 구간으로 나누어 토큰화하고 LLM형 예측에 적용하는 방식을 설명한다. 구간화는 가능한 접근 중 하나다. 모든 시계열 Transformer가 이산 ID를 요구하는 것은 아니며 원문 그림의 모델 이름은 표시만으로 특정하지 않는다.

그림·표·수식 읽기

그림을 보기 전에 다음 해설에서 다룰 축·연산 경로·강조 위치를 찾아보자.

그림 원본

왼쪽 Train Dataset에는 Finance, Electricity, Web Traffic, Retail, Tourism, IoT, Healthcare, Transport, Economics 묶음이 있다. 가운데 Training 화살표는 예측 모델로, 오른쪽 Inference는 New Data로 이어진다. 가운데 모델에는 Input Embedding과 Positional Encoding, Multi-Head Attention, CNN, Add & Norm이 있고 Decoder 쪽에는 Masked Multi-Head Attention, 오른쪽으로 이동한 Outputs 입력, 위쪽 Linear와 Output Forecasts가 표시된다. 따라서 단순한 GPT decoder-only 그림으로 바꿔 읽지 않는다. 이 그림은 데이터 적용 흐름이며 실제 정확도·데이터 수·성능 비교 그래프는 아니다.

앞뒤 연결

142쪽의 구조적 서열 관계에서 시간 순서의 수치 예측으로 옮긴다. 다음 144쪽 구간의 출력확률 학습으로 연결할 때 구간 ID 분포와 원래 수치 복원의 차이를 기억한다.

자료 안에서 확인하기

질문·활동: 구간 [0,1),[1,2),[2,3]을 ID 0,1,2로 정하면 0.2,1.8,2.5와 경계값 1.0은?

예상 결과와 해설

각각 0,1,2이며 1.0은 왼쪽 포함인 두 번째 구간 ID 1이다. ID 1만 알면 1.8인지 1.2인지 복원할 수 없다. 범위 밖 값의 clipping·확장 정책은 별도 정의해야 한다.
