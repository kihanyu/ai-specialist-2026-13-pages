p031. AI 기본 수학: 구분 페이지

학습 안내 · 관련 본문: 02장

기준: 원문 PDF 파일 순서 31쪽. PDF 화면과 텍스트를 함께 조사한 상세 해설이며, 학습에 필요한 내용은 아래와 연결 본문에 풀어 쓴다.

원문에서 실제로 보이는 내용

화면 중앙에 「AI 기본 수학」이라는 제목만 있고 수식·표·학습 실습은 없다. 이전 역사·사회적 맥락에서 수학 단원으로 이동함을 알리는 구분 페이지다. 오른쪽 아래 말풍선 모양은 교안 UI이며 수학 개념 그림이 아니다.

용어·수식·그림의 의미와 조건

보충: 이번 범위의 학습 흐름은 벡터로 표현하기 → 행렬로 변환하기 → 활성화와 확률 → 손실과 학습 → 조건부확률이다. 스칼라는 숫자 하나, 벡터는 순서 있는 숫자 목록이다. 제목에 없는 강의 발언이나 목표를 원문 인용으로 추가하지 않았다.

앞뒤에서 달라지는 점

30쪽까지의 서술에서 32쪽의 좌표·배열 그림으로 바뀐다. 이 페이지 자체에는 계산 내용이 없어 크롭을 만들지 않고 학습 방향을 텍스트로 제시한다.

작은 활동과 해설

활동: 숫자 3과 목록 (3,5)를 구별하라. 예상 답: 앞은 스칼라, 뒤는 두 성분 벡터이며 뒤에서 덧셈·내적의 입력으로 사용한다.

확인 범위

원문 정지 페이지 시각 확인: 충족. 추가 크롭: 해당 없음. 이 페이지의 수식·표·관찰을 텍스트로 풀었으며 반복·제목 그림은 중복 저장하지 않았다. 이 페이지 내용에 대한 남은 원문 대조 문제는 발견하지 않았다. 연결 영상·강사 발언은 조사 범위 밖이며 추정하지 않았다. 독자 이해 검토와 웹 화면 검토는 별도 미확인이다.
