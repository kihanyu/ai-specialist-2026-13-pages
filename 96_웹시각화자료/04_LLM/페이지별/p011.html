p011 · GAN·Diffusion: 생성 방법을 구분하기

학습 안내 · 관련 본문

원문 기준: PDF 파일 순서 11쪽. 텍스트 추출과 실제 렌더링을 함께 확인했다.

원문에 있는 내용

I, Robot 영화 장면, CycleGAN (2017)의 얼룩말↔말 변환, 비디오 생성 정지화면이 나란히 있다. 하단에는 멀티 모달 생성의 시작과 diffusion 모델의 시작이라는 표현이 있다.

뜻과 원리 · 교육용 보충

GAN은 생성기가 만든 표본과 실제 데이터를 구별하는 판별기를 함께 학습시키는 방식이다. CycleGAN은 짝이 정해지지 않은 두 영상 집합 사이의 변환에 되돌림 일관성을 더한다. Diffusion은 데이터를 점점 잡음으로 만드는 과정과 반대로 잡음에서 표본을 복원하는 과정을 학습한다. 영상→영상 변환만으로 텍스트·소리까지 다루는 멀티모달 모델이라고 할 수 없다.

그림·표·수식 읽기

먼저 이 페이지의 표시가 무엇을 비교하거나 연결하는지 확인하자.

그림 원본

CycleGAN 위쪽은 얼룩말→말, 아래쪽은 말→얼룩말의 방향이다. 배경과 동물 형상을 어느 정도 유지하며 외양을 바꾸는 목적을 읽는다. 오른쪽 0:00 영상의 작동 방식은 정지화면만으로 판별할 수 없으므로 실제 모델·음성·내용을 추측하지 않는다.

앞뒤 연결

Attention이라는 구조 이름에서 GAN·Diffusion이라는 생성 학습 방식으로 비교축이 달라진다. 다음 쪽은 GPT 계열의 규모 증가를 다룬다.

작은 활동과 해설

활동: 입력 x를 다른 스타일 G(x)로 바꾸고 다시 F(G(x))로 되돌렸을 때 x와 비슷하도록 제한하는 이유는?

예상 결과·해설: 아무 이미지나 만들지 않고 원래 내용과 연결된 변환을 유도하기 위해서다. 완벽한 원본 보존이나 의미적 정답을 보장하지는 않는다.
