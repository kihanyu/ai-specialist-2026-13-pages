LLM 독립형 교재 — 입력에서 학습과 효율화까지

문장을 숫자로 바꾸고, 문맥에 맞는 다음 토큰 확률을 계산하며, 손실과 보상으로 모델을 바꾸는 과정을 배웁니다. 사칙연산과 좌표에서 시작해 22장으로 이어집니다. 필요한 정의·작은 계산·그림 해석·확인 질문은 이 폴더 안에 있습니다. PDF는 필수 학습 경로가 아닙니다.

처음 읽는 순서

  1. 01장에서 모델의 발전과 사회적 주장을 구분합니다.
  2. 02~05장에서 벡터·미분·분포·조건부 확률을 계산합니다.
  3. 06~14장에서 문자열 → 토큰 → 문맥 표현 → 출력 확률 → 손실과 갱신을 연결합니다.
  4. 15~18장에서 미세튜닝·선호·추론 학습의 목표와 학습 대상을 비교합니다.
  5. 19~22장에서 저장량·메모리 이동·근사 오차의 조건을 비교합니다.

각 장의 확인 질문을 먼저 스스로 풀고 해설을 확인하세요. 계산이 막히면 해당 장의 선행 지식으로 돌아갑니다. 복습은 용어집 또는 280쪽 상세 해설 목차에서 시작할 수 있습니다.
