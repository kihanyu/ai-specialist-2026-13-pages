용어 정의 역할과 주의 설명
벡터 순서가 있는 숫자 목록 입력과 특징을 수치로 표현한다. 2장
내적 대응 성분의 곱을 더한 스칼라 Attention 점수에 쓰이며 길이와 방향의 영향을 함께 받는다. 2장
행렬 행과 열로 구성한 숫자 배열 입력 표현을 다른 표현으로 변환한다. 2장
softmax 여러 점수의 지수를 합으로 나누는 확률 변환 후보별 확률을 만들며 적용 축을 지정해야 한다. 2장
역전파 연쇄법칙으로 손실의 기울기를 뒤로 계산하는 절차 가중치별 갱신 방향을 구한다. 3장
학습률 기울기 갱신의 크기를 조절하는 계수 안정 조건은 손실의 곡률 등 조건에 따라 달라진다. 3장
교차엔트로피 정답 분포로 가중한 예측 로그확률의 음수 평균 정답에 낮은 확률을 준 예측을 큰 손실로 평가한다. 4장
KL 두 분포 사이의 상대적 차이를 나타내는 방향성 있는 양 기준 분포와 예측 분포를 구별하여 비교한다. 4장
PPL 평균 음의 로그확률을 지수화한 예측 난도 지표 토큰화와 문맥 조건이 같은 경우에 비교한다. 4장
조건부 확률 관측 조건으로 표본 공간을 제한한 확률 문맥이 주어졌을 때 다음 토큰을 예측하는 기반이다. 5장
베이즈 사전확률과 우도로 사후확률을 구하는 규칙 관측 뒤 믿음의 기준을 갱신한다. 5장
Transformer Attention을 중심으로 위치 사이의 정보를 결합하는 구조 순차 상태 전달과 다른 문맥 처리 방식을 제공한다. 6장
토큰화 문자열을 모델이 다룰 단위와 ID로 나누는 과정 텍스트와 수치 입력의 경계를 정한다. 7장
임베딩 토큰 ID에 대응하는 학습 벡터 표현 ID를 연산할 수 있는 특징으로 바꾼다. 7장
RoPE 위치에 따라 Q와 K의 좌표쌍을 회전하는 위치 표현 Attention 내적에 상대 위치 관계가 반영되게 한다. 8장
Attention 참고 위치의 가중치를 정해 Value를 가중합하는 계산 문맥에 맞게 각 위치의 표현을 바꾼다. 9장
Query·Key·Value 입력에서 서로 다른 학습 행렬로 투영한 비교 기준·검색 단서·전달 내용 점수 비교와 정보 전달의 역할을 분리한다. 9장
causal mask 미래 위치를 참조하지 못하도록 softmax 전에 점수를 가리는 제약 다음 토큰 학습에서 미래 정답 누출을 막는다. 9장
Multi-head 여러 투영 공간에서 Attention을 병렬 계산하는 방식 결과를 연결하고 출력 투영하여 표현을 결합한다. 10장
잔차 연결 블록 입력을 변환 결과에 더하는 경로 표현과 기울기의 전달을 돕는다. 11장
FFN 각 토큰 위치에 적용하는 특징 변환 신경망 Attention 뒤 특징을 비선형적으로 갱신한다. 11장
정규화 정해진 축의 통계로 값의 규모를 조절하는 연산 LayerNorm과 RMSNorm의 기준 통계를 구별해야 한다. 11장
logit 확률 변환 전 어휘 후보별 점수 softmax와 샘플링의 입력이다. 12장
temperature 샘플링 전 점수의 규모를 바꾸는 계수 분포의 집중도를 조절하며 사실성을 보장하지 않는다. 12장
활성값 현재 입력의 순전파에서 계산되는 중간 값 학습된 가중치와 달리 문맥에 따라 달라진다. 13장
사전학습 대규모 데이터의 예측 목표로 기반 파라미터를 학습하는 과정 이후 미세튜닝이 출발할 표현을 형성한다. 14장
LoRA 기반 가중치를 동결하고 저랭크 행렬의 곱으로 수정량을 학습하는 방법 학습할 파라미터 수를 줄인다. 15장
QLoRA 양자화된 기반 가중치와 저랭크 학습을 결합한 방법 기반 저장량을 줄이며 연산 정밀도와 저장 정밀도를 구별한다. 15장
손실 마스킹 선택한 토큰만 손실의 합과 분모에 포함하는 규칙 대화 학습에서 어떤 응답 토큰을 학습할지 정한다. 16장
RLHF 사람의 선호를 보상 신호로 이용하는 강화학습 절차 응답 선호를 정책 갱신으로 연결한다. 17장
DPO 선호·비선호 응답의 정책과 참조정책 로그확률 차이로 학습하는 목적 선호 쌍으로 상대적 응답 확률을 조정한다. 17장
GRPO 같은 문제의 응답 그룹을 기준으로 상대 보상 신호를 만드는 정책 최적화 그룹 보상을 advantage로 바꾸어 갱신에 사용한다. 18장
advantage 기준과 비교한 응답의 상대적 유리함 부호에 따라 확률비와 clip의 작용이 달라진다. 18장
clip 확률비를 정해진 하한과 상한으로 제한하는 연산 목적함수의 과도한 갱신 유인을 제한한다. 18장
KV 캐시 이전 토큰의 Key와 Value를 저장해 재사용하는 메모리 자기회귀 생성에서 이전 투영의 재계산을 줄인다. 19장
GQA 여러 Query head가 Key·Value head를 공유하는 구조 캐시 크기를 줄인다. 19장
MLA K·V 관련 정보를 저차원 잠재표현으로 압축하는 Attention 방식 캐시 저장과 복원 계산 사이의 비용을 조정한다. 19장
sliding window 참조 가능한 과거 위치를 제한된 창으로 좁히는 방식 Attention 참조 범위와 비용을 줄인다. 20장
상태 갱신 이전 상태와 새 입력으로 다음 상태를 계산하는 과정 전체 이력을 다른 형태의 요약 상태로 전달한다. 20장
FlashAttention 타일 계산과 online softmax로 메모리 이동을 줄이는 정확 Attention 구현 방식 큰 점수 행렬의 저장을 줄이며 근사 Attention과 구별한다. 21장
양자화 연속 값을 제한된 대표값 코드로 근사 저장하는 방법 저장량을 줄이는 대신 오차와 복원 비용이 생긴다. 22장
TurboQuant 회전·양자화·잔차 보정을 조합한 압축 기법 KV 압축에서 저장량과 점수 오차의 조건을 따진다. 22장
